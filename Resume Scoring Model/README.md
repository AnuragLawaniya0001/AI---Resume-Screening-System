## What This Model Does

Takes a raw resume (plain text) → outputs:

```json
{
  "total_score": 72.4,
  "grade": "Good",
  "breakdown": {
    "experience_score": 18.5,
    "education_score":  20.0,
    "skills_score":     21.3,
    "structure_score":  12.6
  },
  "suggestions": [
    "[Experience] Include specific metrics and outcomes for each role.",
    "[Structure]  Add GitHub or portfolio link to strengthen online presence."
  ]
}
```

## How to Run

### Step 0 — Install dependencies
```bash
pip install -r requirements.txt
```

### Step 1 — Generate Dataset
```bash
python generate_dataset.py
```
Creates `data/resume_dataset.csv` with 3000 simulated resumes.
Each row has: `resume_text`, `experience_score`, `education_score`,
`skills_score`, `structure_score`, `total_score`

### Step 2 — Train BERT
```bash
python train_bert.py
```
- Downloads `bert-base-uncased` from HuggingFace (~440 MB, one time)
- Fine-tunes for 5 epochs
- Saves best model to `model/bert_resume_scorer/`

**Training time estimates:**
| Hardware     | Time (5 epochs, 3000 samples) |
|--------------|-------------------------------|
| GPU (T4/V100)| ~8–12 minutes                 |
| CPU only     | ~60–90 minutes                |

**GPU recommended.** Use Google Colab (free T4) if no local GPU.

### Step 3 — Predict
```bash
# Demo with 3 built-in sample resumes
python predict.py

# Score a resume file
python predict.py --file path/to/resume.txt

# Score from command line text
python predict.py --text "John Doe, Python developer, 5 years experience..."
```

## Model Architecture

```
Resume Text (plain string)
        │
        ▼
BertTokenizer (bert-base-uncased)
  max_length=512, padding, truncation
        │
        ▼
BERT Encoder (12 layers, 768-dim)
        │
  [CLS] pooler_output (768-dim)
        │
        ▼
Dropout(0.3)
        │
Linear(768 → 256) + ReLU
        │
Dropout(0.15)
        │
Linear(256 → 4)
        │
Sigmoid × 25
        │
        ▼
[exp_score, edu_score, skill_score, struct_score]   ← each 0–25
        │
        ▼
total_score = sum(4 scores)   ← 0–100
```

**Loss:** MSELoss on all 4 sub-scores simultaneously
**Optimizer:** AdamW, lr=2e-5
**Scheduler:** CosineAnnealingLR

---

## Score Breakdown

| Sub-score          | Max | What it measures                                      |
|--------------------|-----|-------------------------------------------------------|
| experience_score   | 25  | Years of exp, number of jobs, promotions, achievements|
| education_score    | 25  | Degree level (PhD=25, Master=20, Bachelor=15...)      |
| skills_score       | 25  | Number of skills listed, certifications               |
| structure_score    | 25  | Summary, bullet points, LinkedIn/GitHub/Portfolio     |

## Grade Scale

| Total Score | Grade        |
|-------------|--------------|
| 85–100      | Excellent    |
| 70–84       | Good         |
| 55–69       | Average      |
| 40–54       | Below Average|
| 0–39        | Weak         |

## Tips for Better Accuracy

1. **More epochs:** Change `"epochs": 5` to `8` in `train_bert.py` CFG
2. **Larger batch:** If GPU >8GB, set `"batch_size": 16`
3. **Real data:** Replace `data/resume_dataset.csv` with real labeled resumes
4. **Freeze BERT layers:** For fast training, freeze first 8 BERT layers:
   ```python
   for i, layer in enumerate(model.bert.encoder.layer):
       if i < 8:
           for p in layer.parameters():
               p.requires_grad = False
   ```
